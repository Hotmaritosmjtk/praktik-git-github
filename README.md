
# Praktikum Git dan GitHub

## Deskripsi
Proyek ini dibuat untuk memenuhi praktikum
Manajemen Jaringan dan Server.

## Program
File cek_direktori.sh merupakan Bash Script
yang digunakan untuk menampilkan informasi
tanggal dan waktu serta isi suatu direktori.

## Tujuan
Mempelajari penggunaan Bash Script serta
pengelolaan file menggunakan Git.
